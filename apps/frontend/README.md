# Лаб.АИ — frontend

Демонстрационный интерфейс ассистента проверки лабораторных работ. Перенесён из дизайна Рафаэля: обзор работ преподавателя, настройки критериев, загрузка отчёта студентом и пример обратной связи.

## Запуск

Требуются Node.js 20.19+ в ветке 20 либо 22.12+ и npm 10+. Проверено с Node.js 25.6.0 и npm 11.8.0. Требования Vite: [официальная документация](https://vite.dev/guide/).

Из корня репозитория:

```sh
cd apps/frontend
npm ci
npm run dev
```

Откройте **http://127.0.0.1:5173/**. Vite настроен на локальный IPv4-адрес, чтобы запуск не зависел от разрешения `localhost` в IPv6. Держите терминал с `npm run dev` открытым: после остановки процесса сайт недоступен. Используйте `http`, а не `https`.

Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd` вместо `npm`. Перед `npm ci` остановите dev/preview через `Ctrl+C`: на Windows запущенный Vite может блокировать замену нативных зависимостей. Если порт 5173 занят, Vite сообщит об этом; автоматического перехода на другой порт нет.

```sh
npm run typecheck
npm run lint
npm run build
npm run preview
```

`build` включает проверку TypeScript и создаёт `dist/`. `preview` позволяет проверить production-сборку локально по адресу **http://127.0.0.1:4173/**; его терминал также должен оставаться открытым.

## Стек и структура

React 19, TypeScript со строгой проверкой, Vite 8, Tailwind CSS 4 и исходные пользовательские CSS-правила. ESLint проверяет TypeScript и React hooks. Навигация и данные хранятся в React state; маршрутизатор и библиотеки управления состоянием не нужны.

```text
src/
  app/App.tsx              — навигация, общие данные и уведомления
  components/layout/      — Sidebar
  components/ui/          — SVG-иконки, Modal, HelpModal, CriteriaAssessment
  features/teacher/       — обзор работ, настройки, карточка работы
  features/student/       — выбор файла, демопроверка, результат
  data/mockData.ts         — работы, лабораторная, критерии и тестовый результат
  types/                  — типы данных и пропсов
  hooks/useToast.ts        — уведомления с очисткой таймера
  utils/                  — проверка расширений, распределение демобаллов
  styles/                 — исходный дизайн и небольшие исправления доступности
  index.tsx               — единственная точка входа, подключена в index.html
public/fonts/             — Manrope и лицензия SIL OFL
```

Сохранены исходные SVG-иконки, цвета, размеры, отступы и состояния компонентов. Manrope поставляется локально из [репозитория Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope); запросов к Google Fonts при запуске нет. Favicon использует существующий символ приложения. Инфраструктура Figma Make в сборку не включена.

## Как пользоваться

- Преподаватель: найдите студента, выберите группу или статус, откройте работу, изучите критерии, добавьте комментарий и примите работу либо отметьте необходимость доработки.
- Настройки ИИ: заполните любую из четырёх вкладок текстом или выберите PDF, DOCX, TXT. Кнопка сохранения поясняет срок хранения данных.
- Студент: нажмите стрелку в профиле внизу боковой панели. Выберите PDF/DOCX или перетащите его в область загрузки, запустите демопроверку, изучите пример результата. «Начать новую попытку» сбрасывает выбранный файл и результат.
- «Как пользоваться» открывает краткую инструкцию. Модальные окна закрываются крестиком, кликом по фону и Escape; фокус удерживается внутри окна и возвращается к открывшей его кнопке.

## Границы демонстрации

Все семь работ, сроки, оценки и замечания — тестовые данные. Счётчики вычисляются из массива работ и обновляются при локальном изменении статуса. Сейчас доступна одна страница таблицы; недоступные страницы отключены. Поиск, фильтры, сортировка и выбор строк работают в браузере.

Файлы не читаются, не анализируются и не отправляются на сервер. Проверяется только расширение. Демо студента после небольшой задержки всегда показывает **82/100** и один и тот же чек-лист. Оценки по критериям в карточке работы распределены пропорционально тестовому общему баллу; это не вывод LLM.

Настройки, выбранный файл, решения и комментарии сохраняются в памяти до перезагрузки страницы. Комментарий сохраняется при нажатии «Принять работу» или «На доработку». Кнопки скачивания тестовых документов и отправки преподавателю сообщают, что операция недоступна. Переключение роли — демонстрационная навигация, не авторизация.

Backend API, локальная LLM, Moodle/LTI, серверное хранение и настоящая отправка результатов не подключены. Для следующего этапа нужно согласовать контракт API с backend-командой: реальные идентификаторы, материалы проверки, загрузку файлов, состояния обработки, формат результатов и сохранение решений. После этого заменить источники mock-данных и локальные обработчики, отдельно подключить авторизацию/LTI и обработку сетевых ошибок.

## Техническая проверка

В ходе финального аудита выполнены `npm ci`, `npm run typecheck`, `npm run lint`, `npm run build`. В Chrome проверены оба режима, фильтры, поиск и сортировка, выбор строк, комментарии и счётчики, суммы критериев, вкладки настроек, неправильные форматы, PDF/DOCX и drag-and-drop, демопроверка, повторная загрузка, новая попытка, уведомления, закрытие модальных окон и управление фокусом. Отдельно проверено переключение ролей во время демопроверки.

Проверены размеры 1440×900, 1024×768, 900×700, 768×900 и 390×844, а также окна высотой 320–400 px. При первоначальном переносе сравнение проводилось с исходником из ZIP, с одинаковым локальным Manrope в обеих версиях: на desktop совпали геометрия основных блоков и типографика. Перед удалением архива подтверждена сохранность исходных CSS-правил. На узких экранах таблица прокручивается отдельно; в низких окнах sidebar имеет собственную прокрутку. В проверенных сценариях нет глобального горизонтального переполнения и ошибок консоли.

Отдельно проверен `npm run preview`: загрузка production-сборки и локального шрифта, работа внутри iframe 900×700, переключение роли и помощь на мобильной ширине. Внешних сетевых запросов и ошибок консоли не обнаружено. Это проверка контейнера, не интеграция с Moodle/LTI.

После аудита удалены исходный `design-source.zip`, временные скрипты, снимки и каталог `.qa/`. Эти разовые проверки не являются поддерживаемым набором автотестов. `node_modules/` и `dist/` исключены из Git; исходники, локальный Manrope с лицензией и `package-lock.json` сохранены.
